# 团校积分系统

一个完整的学分管理系统，采用 Windows 11 风格界面设计。

## 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 初始化管理员（默认账号：system/admin，密码：css2025txmsc）
python init_admin.py

# 3. 启动系统
python app.py                    # 开发环境
start_server.bat                 # 生产环境（Windows）
./start_server.sh                # 生产环境（Linux）

# 4. 访问系统
# 学生登录：http://localhost:5000
# 管理员登录：查看日志中显示的地址
```

## 核心功能

### 学生端
- 查看个人学分和活动列表
- 修改密码、忘记密码（邮件重置）
- 活动报名（支持自定义问卷）
- 导出学分报告PDF

### 管理员端
- 学生管理（添加/删除/修改/批量导入）
- 活动管理（创建/编辑/删除/权限控制）
- 学分录入（单个/批量添加）
- 问卷管理（创建问卷、查看报名、候补机制）
- 数据统计和导出（Excel/PDF）
- 智能学分分配（DFS算法）

### 系统管理员
- 管理员账号管理
- 部门管理
- 类别和总学分设置
- 邮箱配置

## 技术栈

- **后端**：Flask 3.0.0 + Waitress
- **前端**：原生 HTML/CSS/JavaScript
- **数据存储**：JSON 文件（含并发控制）
- **密码加密**：SHA-256
- **UI 设计**：Windows 11 Fluent Design
