# 自定义问卷功能使用指南

> 面向问卷创建者与填写者。登录统一为"密码 + 动态验证码（OTP）"两步验证。

## 0. 重要变化：不再有"注册问卷"

手机号、微信号、建议已并入**学生档案**。学生在"报名信息"页
（学生端 → 报名信息）自行填写和维护，报名活动问卷时系统会**自动把联系方式
填入问卷正文**，无需重复填写；未填手机号或微信号的学生无法提交报名。
本指南只介绍**活动问卷**与**独立问卷**。

两类问卷：

- **活动问卷**：绑定某个活动（通常还绑定活动下的一条记录），用于活动报名，
  可收集"意向学分类别"。同一活动同时只能有一个进行中的问卷。
- **独立问卷**：不绑定任何活动，用途自由（调查、信息收集等）。
  仅系统管理员可以创建。

## 1. 创建问卷（管理员）

入口：管理端 → 问卷管理 → "创建问卷"，进入**问卷设计器**。

### 1.1 填写基本信息

- **活动**：选择要绑定的活动；系统管理员额外可以选"无（独立问卷）"。
- **绑定记录**（活动问卷必选）：选择该活动下的一条记录。绑定后：
  - 记录只有一个学分类别 → 学生的意向类别自动归入该类别，无需提问；
  - 记录有多个类别 → 自动生成"意向学分类别"单选题，学生不选时记为"无"；
  - 设计器会据此给出提示文字。
- **问卷标题**、**开始时间 / 结束时间**（开始必须早于结束）、
  **最大报名人数**（0 = 不限）。
- 同一活动已有进行中问卷时，不能再创建第二个。

### 1.2 编辑正文文档

问卷正文是一篇可以直接打字的文档（支持 **Markdown** 与 `$...$` 数学公式），
左侧提供两类可插入的"芯片"，点击插入光标处或拖入文中：

**信息字段**（自动填入的值，可重复使用）：

| 字段 | 含义 |
| --- | --- |
| 姓名 / 学号 | 取自登录学生档案 |
| 手机号 / 微信号 | 取自"报名信息"页 |
| 活动名称 / 记录名称 | 问卷绑定信息 |
| 意向类别 | 多类别记录时是学生的文内单选 |

**题目字段**（6 种题型，见第 2 节）：插入后在正文中显示为题目槽位。
每道题**必须放入正文恰好一次**，保存时前后端都会检查；删除题目会同步移除槽位。
选中正文中的题目芯片，在右侧面板编辑题目属性。

设计器内置默认开头模板（如"张三（学号：…）现向你报名…的…，并且希望优先将
活动学分归入…类别。"），整篇文字都可以随意修改，只是起点。

### 1.3 保存与版本

- 保存时校验：标题、时间、题目文本、选择题至少 2 个不重复选项、
  评分上限 2–10、数字题最小 ≤ 最大、正则表达式合法等。
- 修改标题、题目、正文或绑定记录后保存，**版本号 +1**；只改时间不升版本。
  学生已提交的记录始终按**提交时的版本快照**展示，不受后续修改影响。

### 1.4 关闭与删除

- 问卷管理 → 进入某个问卷 → 可"删除问卷"（连同全部报名记录一起删除）。
- 状态可改为"已关闭"：学生不能再报名，已有报名保留。

## 2. 题型与配置

| 题型 | 可配置 | 学生端表现 |
| --- | --- | --- |
| 单选题 | 选项（≥2 个、不重复）；必填；允许"其他"自定义项 | 单选，勾"其他"可自由填写 |
| 多选题 | 同上 | 多选，支持"其他" |
| 文本题 | 必填；多行作答（简答）；字数上限（1–5000）；格式校验 | 单行/多行输入 |
| 数字题 | 必填；最小值/最大值 | 数字输入，超出范围报错 |
| 日期题 | 必填 | 日期选择，须为合法日期 |
| 评分题 | 必填；评分上限（2–10，默认 5） | 1 到上限打分 |

**文本题格式校验**预设：

- 无校验（默认）
- 手机号（`1` 开头 11 位）
- 邮箱
- 身份证号（18 位）
- 自定义正则（如 `^[A-Z]\d{5}$`，保存时校验合法性）

必填题不填会被拒绝提交；所有校验后端会再强制一遍。

## 3. 学生报名流程

入口：学生端 → 活动报名。

1. **可报名问卷**标签页列出当前时间窗内的问卷：标题、活动、起止时间、
   已报名/上限。名额已满的问卷显示"可候补"——**报名不会被拒绝，而是按
   提交顺序进入候补名单**。
2. 首次报名前需先在"报名信息"页填好手机号和微信号，否则系统会引导前往。
3. 点击"立即报名 / 候补报名"打开填写窗口：个人信息已自动填入正文；
   点击文中的题目槽位，在右侧作答；多类别问卷在正文中选择意向类别
   （不选记为"无"）。
4. 提交后显示结果；在**我的报名**标签页可随时查看：
   - 进行中：名次（如 `8/50`，超出名额显示"候补"）或报名顺序（不限名额时）；
   - 截止后：最终"报名成功 / 报名失败"。
5. **修改**：截止前可修改答案与意向类别，**修改不会改变名次**。
6. **取消报名**：截止前可取消，名额立即让给后面的候补；想再报名可重新提交，
   名次按新的提交时间排到当前末尾。

## 4. 现场签到

管理员在问卷详情页"开启签到"后：

- 名额内的报名者自动获得一个**独立的 6 位一次性签到码**（候补需管理员
  逐人"生成"）。签到码只在管理员端显示，请现场向管理员索取，或扫管理员
  出示的**本人二维码**。
- 学生在"我的报名"中点"签到"，输入 6 位码或扫码即可；签到成功后码立即作废，不能重复使用。
- 管理员可确认/代签、取消签到（可重新签到）、标记缺席。
  被标记缺席的报名**不再占用名额**，候补按顺序自动转正——所以候补同学
  也请留意自己的名次变化。

## 5. 管理端查看与导出

进入问卷管理 → 点击问卷卡片：

- **填写记录**：排名、学号、姓名、联系方式、意向类别、提交时间、版本、
  状态（成功/候补/已取消，截止后为成功/失败）、签到状态；支持搜索；
  "详情"按学生提交时的问卷版本展示每题答案与合成正文；"编辑"可更正联系方式
  与意向类别；"删除"可移除单条记录。
- **导出记录**：下载 xlsx，包含基本信息、状态、版本、签到信息与每道题一列
  （多选答案以顿号连接；模板改过也不怕——列取当前题目与历史快照题目的并集）。

## 6. 常见问题

**Q：学生说报不了名？**
检查：问卷是否在时间窗内且未关闭；学生是否已在"报名信息"页填写手机号
和微信号；是否重复报名同一问卷。

**Q：名额满了还能报吗？**
能。超额报名进入候补，按提交顺序排队；有人取消或被标记缺席时自动转正。

**Q：修改报名会影响排名吗？**
不会，修改只改答案，名次按最初提交时间计算；取消后重报则按新提交时间重新排队。

**Q：意向类别可以事后改吗？**
可以。学生截止前可自行修改；管理员也可在记录"编辑"中修改，
但仍限于该记录的可行类别（多类别时可为"无"）。

**Q：问卷改过了，以前的答案会乱吗？**
不会。每次提交都保存当时的问卷快照与版本号，详情与导出按提交时的版本解读。

**Q：签到码输错了/被别人用了？**
签到码每人一码、只对本人有效，签到成功立即作废。输错可重试；
码不见了可请管理员在记录行重新"生成"（候补同样适用）。

**Q：为什么有的问卷我（普通管理员）看不到？**
独立问卷仅系统管理员可见；活动问卷只有对该活动有编辑权限的管理员才能管理。
