## 核心功能

### 1. 学生功能

#### 1.1 查看学分
- 查看个人总学分和各类别学分
- 查看活动参与详情
- 查看合格状态（总学分 + 各类别）
- 智能学分分配（DFS算法优化）

#### 1.2 修改密码
- 学生可以自行修改密码
- 客户端SHA-256哈希传输

#### 1.3 忘记密码
- 通过邮件重置密码
- 系统自动生成新密码并发送到学生邮箱

#### 1.4 查看活动列表
- 按类别查看所有活动
- 查看活动所属类别

### 2. 管理员功能

#### 2.1 学生管理
- **添加学生**：单个添加或批量导入
- **修改学生**：修改姓名、密码
- **删除学生**：删除学生及相关数据
- **批量导入**：CSV格式（学号,姓名,密码）
- **导出学生**：导出学生名单CSV

**权限**：
- 系统管理员：完全权限
- 普通管理员：只读权限（查看列表，不含密码）

#### 2.2 活动管理
- **创建活动**：设置名称、类别、部门
- **修改活动**：修改类别、部门、权限
- **删除活动**：删除活动及所有记录
- **权限管理**：设置允许编辑的管理员列表

**权限**：
- 系统管理员：管理所有活动
- 普通管理员：只能管理有权限的活动
- 创建者自动获得编辑权限

#### 2.3 记录管理
- **添加记录**：在活动下创建记录
- **修改记录名称**：修改记录的名称
- **删除记录**：删除记录及所有条目
- **查看详情**：查看记录中的所有学分条目

**权限**：
- 继承活动的编辑权限

#### 2.4 学分录入
- **单个添加**：为单个学生添加学分
- **批量添加**：批量导入学分（姓名或学号,学分）
- **修改学分**：修改已有学分条目
- **删除学分**：删除学分条目
- **批量操作**：批量修改、批量删除

**特性**：
- 支持为不存在的学生添加学分（学号为纯数字即可）
- 支持按姓名或学号查找学生
- 支持多选类别

#### 2.5 类别管理
- **添加类别**：创建新的学分类别
- **修改类别**：修改类别的合格学分要求
- **删除类别**：删除类别
- **设置合格标准**：设置每个类别的合格学分

**权限**：
- 仅系统管理员可以管理类别

#### 2.6 数据统计
- **学生学分统计**：查看所有学生的学分情况
- **类别统计**：各类别合格人数和比例
- **分数段统计**：学分分布情况
- **活动统计**：按类别统计活动数量
- **导出报表**：导出Excel统计表

**权限**：
- 系统管理员：查看所有统计数据
- 普通管理员：查看部分统计数据（不含学生详情）

### 3. 系统管理员专属功能

#### 3.1 管理员账号管理
- **添加管理员**：创建新的管理员账号
- **修改密码**：修改管理员密码
- **修改部门**：修改其他管理员的部门
- **删除管理员**：删除普通管理员账号
- **角色管理**：设置管理员角色（系统管理员/普通管理员）

**限制**：
- 不能删除自己的账号
- 不能删除系统管理员账号
- 不能修改自己的部门

#### 3.2 部门管理
- **添加部门**：创建新的部门
- **删除部门**：删除部门

#### 3.3 系统设置
- **总学分设置**：设置合格总学分要求
- **类别管理**：管理所有学分类别
- **邮箱配置**：配置SMTP邮箱用于发送密码重置邮件

## 权限管理

### 角色定义

#### 系统管理员 (system_admin)
- 拥有所有权限
- 可以管理学生、活动、类别、部门、管理员
- 可以查看所有统计数据
- 可以修改其他管理员的部门
- 不能被删除
- 不能修改自己的部门

#### 普通管理员 (admin)
- 可以查看学生列表（不含密码）
- 可以管理有权限的活动
- 可以录入学分
- 可以查看部分统计数据
- 不能管理类别、部门、管理员
- 可以被删除

#### 学生 (student)
- 只能查看自己的学分
- 可以修改自己的密码
- 可以使用忘记密码功能
- 可以查看活动列表

### 活动权限

#### 权限模型
- 每个活动有一个 `allowed_editors` 列表
- 创建活动时，创建者自动加入列表
- 系统管理员可以完全控制权限列表

#### 权限检查
```python
def check_activity_edit_permission(activity_id):
    # 系统管理员或在允许编辑列表中
    return (is_system_admin or 
            current_admin_id in activity.allowed_editors)
```

#### 权限继承
- 记录继承活动的编辑权限
- 学分条目继承记录的编辑权限

## 数据模型

### Student（学生）
```python
class Student:
    student_id: str      # 学号（纯数字）
    name: str            # 姓名
    password: str        # 密码（明文）
```

### Admin（管理员）
```python
class Admin:
    admin_id: str        # 账号
    password: str        # 密码（明文）
    role: str            # 角色（system_admin/admin）
    department: str      # 所属部门
```

### Category（类别）
```python
class Category:
    name: str                  # 类别名称
    required_credits: float    # 合格学分
```

### Activity（活动）
```python
class Activity:
    activity_id: str           # 活动ID（UUID）
    name: str                  # 活动名称
    categories: list           # 所属类别列表
    department: str            # 负责部门
    created_by: str            # 创建者ID
    allowed_editors: list      # 允许编辑的管理员列表
    records: list              # 记录列表
```

### Record（记录）
```python
class Record:
    record_id: str             # 记录ID（UUID）
    activity_id: str           # 所属活动ID
    record_name: str           # 记录名称
    entries: list              # 学分条目列表
```

### Entry（学分条目）
```python
class Entry:
    student_id: str            # 学生学号
    credits: float             # 学分
    categories: list           # 可选类别列表
```

## 智能学分分配算法

### 算法概述
使用深度优先搜索（DFS）+ 剪枝优化，找到能让最多类别合格的学分分配方案。

### 算法流程
1. 收集学生的所有学分条目
2. 使用DFS遍历所有可能的类别分配方案
3. 使用剪枝优化搜索效率
4. 选择能让最多类别合格的分配方案

### 优化策略
- **剪枝**：如果当前合格数+剩余条目数 ≤ 最优解，则剪枝
- **排序**：优先尝试未合格的类别
- **提前终止**：如果所有类别都合格，立即返回

### 复杂度分析
- **时间复杂度**：O(K^N)，其中K是平均可选类别数，N是条目数
- **实际复杂度**：由于剪枝优化，远小于理论值
- **空间复杂度**：O(N + M)，其中M是类别数

## 合格规则

学生需要同时满足：
1. **总学分合格**：总学分 ≥ 设定的合格总学分
2. **所有类别合格**：每个类别的学分都 ≥ 该类别的合格学分

## 批量操作格式

### 批量导入学生
```
2021001,张三,123456
2021002,李四,password123
0001,王五
```
- 格式：学号,姓名,密码
- 密码可省略，默认 `123456`

### 批量添加学分
```
2021001,2
张三,3
李四,1.5
```
- 格式：姓名或学号,学分
- 纯数字视为学号
- 非数字视为姓名
