# 问卷系统完整功能说明

## 功能概述

团校积分系统的问卷功能包括：
1. **注册问卷** - 学生注册时填写基本信息
2. **活动问卷** - 活动报名问卷，支持自定义题目
3. **候补机制** - 名额满后自动候补，按时间排序
4. **问卷管理** - 管理员统一管理所有问卷

## 一、注册问卷

### 功能
- 学生注册时自动创建
- 包含手机号、微信号、建议
- 管理员可以查看和编辑

### 使用
1. 学生注册账号时填写
2. 登录后可在"注册问卷"页面修改
3. 管理员在"问卷管理"中查看

## 二、活动问卷

### 基本功能
- 管理员为活动创建报名问卷
- 设置报名时间和人数限制
- 学生在时间范围内报名

### 固定题目
**意向学分类别**（单选，必填）
- 从活动的学分类别中选择
- 用于后续学分分配

### 自定义题目（新功能）

#### 支持的题型

**1. 说明文字**
- 显示说明、提示信息
- 不需要学生回答
- 用于分隔或说明

**2. 单选题**
- 学生只能选择一个选项
- 至少需要2个选项
- 可设置为必填

**3. 多选题**
- 学生可以选择多个选项
- 至少需要2个选项
- 可设置为必填

**4. 填空题**
- 单行文本输入
- 可设置最大字符数（默认200）
- 可设置为必填

**5. 简答题**
- 多行文本输入
- 可设置最大字符数（默认500）
- 可设置为必填

## 三、候补机制

### 工作原理
1. 活动设置最大报名人数
2. 学生按报名时间排序
3. 前N名为正式名额
4. 第N+1名及以后为候补
5. 名额满后仍可继续报名

### 状态显示

#### 学生端 - 可报名列表
- 名额充足：显示"立即报名"
- 名额已满：显示"可候补"，按钮为"候补报名"
- 已报名且在名额内：显示"已报名"
- 已报名但候补：显示"候补"

#### 学生端 - 我的报名
**未截止时：**
- 名额内：显示"已报名" + 排名
- 候补：显示"候补" + 排名(候补)
- 可以修改和取消

**已截止后：**
- 入选：显示"✓ 已入选" + 绿色提示
- 未入选：显示"未入选" + 红色提示
- 不能修改和取消

#### 管理员端
- 显示排名列
- 未截止：显示"已报名"/"候补"
- 已截止：显示"✓ 已入选"/"未入选"
- 显示候补人数统计

## 四、管理员端操作

### 创建问卷

1. 进入"问卷管理"页面
2. 点击"➕ 创建问卷"
3. 填写基本信息：
   - 选择活动
   - 输入问卷标题
   - 设置开始/结束时间
   - 设置最大报名人数（0=不限）

4. 添加自定义题目：
   - 点击题型按钮（说明/单选/多选/填空/简答）
   - 填写题目文本
   - 设置是否必填
   - 对于选择题：添加/删除选项
   - 对于文本题：设置最大字符数

5. 题目管理：
   - 使用 ↑↓ 按钮调整顺序
   - 点击"删除"移除题目

6. 点击"创建"完成

### 编辑问卷

1. 在问卷列表中找到问卷
2. 点击"编辑"按钮
3. 修改基本信息和自定义题目
4. 点击"保存"

### 查看报名记录

1. 展开问卷
2. 查看报名列表（显示排名、状态）
3. 点击"详情"查看完整信息
4. 点击"编辑"修改报名信息
5. 点击"删除"删除报名记录
6. 点击"📥 导出记录"导出CSV

### 问卷状态

- **进行中**（绿色）- 在报名时间内
- **已截止**（灰色）- 超过结束时间
- **已关闭**（红色）- 管理员手动关闭

## 五、学生端操作

### 填写问卷

1. 进入"活动报名"页面
2. 在"可报名问卷"中选择问卷
3. 系统自动检查注册问卷必填字段
4. 填写意向学分类别（必填）
5. 填写自定义题目
6. 点击"提交"

### 修改报名

1. 在"我的报名"中找到记录
2. 点击"修改"按钮
3. 答案自动回填
4. 修改意向类别和自定义答案
5. 点击"提交"

### 取消报名

1. 在"我的报名"中找到记录
2. 点击"取消报名"
3. 确认取消

**注意：** 截止后不能修改和取消

## 八、常见问题

### Q1: 如何创建带自定义题目的问卷？
A: 在创建问卷时，点击题型按钮添加题目，填写内容后点击"创建"。

### Q2: 学生可以修改已提交的答案吗？
A: 可以，在截止前可以修改意向类别和自定义答案。

### Q3: 如何查看学生填写的自定义答案？
A: 在问卷管理页面，展开问卷后点击"详情"按钮查看完整答案。

### Q4: 候补机制如何工作？
A: 按报名时间排序，前N名为正式名额，超出的为候补。截止后前N名显示"已入选"，其他显示"未入选"。

### Q5: 如何调整题目顺序？
A: 使用题目右上角的 ↑↓ 按钮调整顺序。

### Q6: 选择题至少需要几个选项？
A: 至少需要2个选项。

### Q7: 如何设置必填题？
A: 在题目编辑器中勾选"必填"复选框。

### Q8: 学生报名前需要什么条件？
A: 需要先在注册问卷中填写手机号和微信号。

### Q9: 如何导出包含自定义答案的数据？
A: 在问卷管理页面点击"📥 导出记录"按钮，导出的CSV包含所有信息。

### Q10: 创建问卷时模态框太长怎么办？
A: 模态框会自动显示滚动条，可以滚动查看所有内容。
